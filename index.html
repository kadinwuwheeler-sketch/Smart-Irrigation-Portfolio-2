01 — Project

Engineering Report

The Problem: Standard home watering systems operate on arbitrary timers — running for a fixed duration regardless of actual soil conditions. This can lead to unnecessary watering when the soil already has sufficient moisture.

DESIGN BASIS Final prototype specifications

The PLA housing protects the dry-side electronics; water stays in separate tubing. Dimensions are outside dimensions of the printed housing, not dimensions of the Arduino board.

ParameterDesign specificationsEngineering rationale

02 — Electronics
Arduino C++ Control Logic
In this illustrative calibration, 250 ADC counts represents the wet reference and 485 the dry reference (higher means drier). At 450 counts, relative wetness is (485 − 450) / (485 − 250) × 100 ≈ 14.9%. When the reading reaches 450 or higher, the Arduino commands the relay to turn on the separate 5 V pump for a 20-second pulse. It waits until the reading falls to 426 or lower (~25% wetness) before another pulse can occur.
// 
const int SENSOR_PIN = A0;
const int RELAY_PIN = 7;
const int START_AT = 450;     // ~15% relative wetness
const int REARM_AT = 426;     // ~25% relative wetness
const unsigned long PUMP_MS = 20000;
bool armed = true;
bool pumping = false;
unsigned long pumpStarted = 0;

void setup() {
  pinMode(RELAY_PIN, OUTPUT);
  digitalWrite(RELAY_PIN, HIGH); // OFF for example active-LOW relay
}
void loop() {
  const int reading = analogRead(SENSOR_PIN);
  if (pumping) {
    if (millis() - pumpStarted >= PUMP_MS) {
      digitalWrite(RELAY_PIN, HIGH); // OFF
      pumping = false;
    }
  } else if (!armed && reading <= REARM_AT) {
    armed = true;
  } else if (armed && reading >= START_AT) {
    armed = false;
    pumping = true;
    pumpStarted = millis();
    digitalWrite(RELAY_PIN, LOW); // ON; active-LOW example only
  }
}


03 — Data & Iteration Log
Iteration 1

Bench test: during a 15-minute water-flow trial, the first printed gasket junction developed visible seepage after approximately 4 minutes. The fault was traced to uneven gasket seating, not an asserted maximum pressure rating.

✗ Mechanical valve leaked
Fix

Redesign: I added a 1.2 mm lip to retain the gasket and reprinted the revised part at 40% infill. In three separate 15-minute low-pressure water-flow trials, the observed junction remained dry. This is a bench leak check, not a pressure certification.

✓ 3 × 15 min leak checks passed
Iteration 2

Functional test: 10 dry-threshold trials at 450 counts or higher produced 10 pump starts; each completed one 20-second watering pulse. Readings remained disarmed until 426 counts or lower, avoiding immediate repeated cycles. A sample collection test delivered 120 mL in 20 seconds (360 mL/min) under the stated tubing arrangement; actual output depends on pump head and tubing.

✓ 10/10 triggers; 20 s cycles

Field Research — Singapore 2025

Gardens by the Bay — Observation Notes

At Gardens by the Bay, I considered how integrated structures, managed growing environments, and resource efficiency might inform a smaller engineering project. These are my takeaways to confirm against my own visit notes:

  • Supertree Grove — integrated systems: Structures can serve more than one purpose. Takeaway: Consider how an irrigation enclosure can combine sensor mounting, protection, and maintenance access instead of treating each as a separate part.
  • Flower Dome — environmental control: Controlled growing environments depend on monitoring conditions, not simply following a fixed schedule. Takeaway: Use measured soil conditions to inform watering decisions.
  • Water stewardship — resource efficiency: Gardens are a useful place to ask where water comes from, how it is used, and where it goes. Takeaway: Future tests should measure water delivered against a timer-based baseline, rather than assuming savings.

These are project takeaways inspired by the visit, not claims that I personally tested the Gardens' infrastructure.

02 — Inspiration

The Singapore Connection

Systems efficiency as a design philosophy

Living in Singapore exposed me to infrastructure that treats resource efficiency not as a constraint, but as a design objective. Singapore's water-reuse initiatives, including NEWater, and its Mass Rapid Transit (MRT) network encouraged me to think about how interconnected systems use limited resources. They inspired a practical question: could a small irrigation device also make decisions using real-time feedback?


This project applies that philosophy at the residential scale — replacing arbitrary timer-based irrigation with closed-loop sensor feedback. The goal is to respond to actual conditions and eventually quantify whether that approach uses less water.
